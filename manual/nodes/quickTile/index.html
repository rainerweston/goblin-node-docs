Quick Tile

Quick Tile

Use Quick Tile to repeat an input reliably with controls aimed at tileable outputs. It is a fast route to seamless patterns before additional variation passes.

Availability

This node requires Pro.

Common uses

  • Apply distortions after establishing a stable base pattern.
  • Use mild distortion early and stronger effects near the end for control.

Input ports

  • input

  • Typically expects an image input plus optional control inputs.

Output ports

  • out

  • mask

  • Outputs transformed image data in the same graph branch.

Parameters

ParameterTypeDefaultRange or values
Mask Warping Hfloat0-100 to 100
Mask Warping Vfloat0-100 to 100
Mask Size Hfloat0.150 to 1
Mask Size Vfloat0.150 to 1
Mask Precision Hfloat0.50 to 1
Mask Precision Vfloat0.50 to 1

Behavior

  • Distortion nodes remap sampling coordinates rather than direct color values.
  • Input continuity strongly influences final distortion quality.

Common mistakes

  • Aggressive warps can stretch artifacts and expose seams.
  • Coordinate-heavy chains can become hard to debug without checkpoints.
